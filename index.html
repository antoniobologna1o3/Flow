Connect Spotify / Apple Music

Streaming APIs require a registered developer app, server-side OAuth secrets, and (for Spotify) a Premium account for full-track playback — none of which can be safely embedded in a downloadable client. Rather than faking a search that returns random unrelated songs, Flow keeps this path honest:

  • ✅ Use Your Music to import any song you own or have rights to as a local file — full accuracy, works offline.
  • 🛠️ If you run your own backend, drop your Spotify/Apple client credentials into js/streaming-config.js and flip ENABLED = true — Flow already calls the hook in js/streaming.js.
