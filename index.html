Spotify / Apple Music

Full-track playback from either service needs a registered developer app, OAuth secrets held on a server, and a paid account — none of which can be shipped safely inside a downloadable client. The workaround other sites use is searching by song name, which is exactly the "random artist, same title" mess you didn't want.

  • Working path: Your Music imports any file you own. Exact song, exact cover, works offline.
  • If you host a backend: add your credentials in js/streaming-config.js and set ENABLED = true — the hooks are already wired in js/streaming.js.
